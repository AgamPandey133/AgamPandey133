### 🔥 Featured Engineering Projects

#### 🤖 [Repolens — AI Codebase Intelligence & Autonomous PR Review Agent](https://github.com/AgamPandey133/Repolens)
> *Next.js &bull; TypeScript &bull; PostgreSQL &bull; pgvector &bull; Prisma &bull; Google Gemini API &bull; GitHub Webhooks &bull; Recall.ai &bull; AssemblyAI*

An intelligent developer platform that answers deep semantic questions across codebases and autonomously reviews pull requests with hallucination guardrails.
- **3-Stage Hybrid RAG Pipeline:** Combines dense semantic vector search via `pgvector` (768-dim embeddings), sparse BM25 keyword re-ranking, and Gemini re-ranking to isolate the top 5 high-signal code chunks.
- **4-Step Agentic PR-Review Bot:** Implements an autonomous agent loop (`Plan` ➔ `Retrieve` ➔ `Review` ➔ `Reflect`) triggered via GitHub webhooks. The **Reflect** stage cross-examines generated review comments against ground-truth codebase context to eliminate false positives.
- **AI Observability & Evaluation:** Built real-time telemetry scoring **faithfulness (0–100)** for every LLM answer, alongside latency, token expenditure, and error tracking across 6 distinct AI pipelines.
- **Scale:** Engineered with ~10.7K lines of production TypeScript, 19 REST API routes, and 11 relational database models.

#### 🌐 [Teachmate — Real-Time Peer-to-Peer Learning & Context-Aware AI Tutor](https://github.com/AgamPandey133/Teachmate)
> *MERN Stack &bull; Socket.IO &bull; WebRTC &bull; WebSockets &bull; Gemini Embeddings &bull; JWT Auth*

A scalable, full-stack collaborative platform connecting students and mentors via live communication protocols and an adaptive AI tutor.
- **Real-Time Video & Chat Infrastructure:** Built low-latency peer-to-peer WebRTC video streaming with Socket.IO signaling, handling live presence, synced study timers, and 9 custom socket events.
- **Context-Aware Vector RAG Tutor:** Vectorized learning vocabulary into 3072-dimensional Gemini embeddings stored in MongoDB; executed in-memory cosine similarity retrieval to inject the top 5 relevant pedagogical concepts into each conversational turn.
- **Production Backend Architecture:** Built 24 secure REST endpoints, 4 relational-mapped Mongoose models, HTTP-only cookie-based JWT authentication, and bcrypt password hashing across 13 client views.
